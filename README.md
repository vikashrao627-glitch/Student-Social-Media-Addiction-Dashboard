# 📌 Project Overview

Social media has become an essential part of students' daily lives. While it offers numerous benefits, excessive usage can negatively affect academic performance, sleep quality, mental well-being, and personal relationships.

This Power BI dashboard transforms raw student data into meaningful insights using interactive visualizations, DAX measures, Power Query transformations, slicers, drill-through reports, and bookmarks.

The dashboard enables users to explore trends, compare student groups, and identify factors associated with social media addiction.

---

# 🎯 Business Objectives

- Analyze students' daily social media usage.
- Measure addiction levels across different student groups.
- Evaluate the impact on academic performance.
- Understand lifestyle habits such as sleep duration.
- Explore mental health patterns.
- Analyze relationship conflicts.
- Build an interactive dashboard for data-driven decision-making.

# 📈 Key Insights

- Students with higher daily social media usage tend to have higher addiction scores.
- Reduced sleep duration is associated with increased social media usage.
- Academic performance generally decreases as addiction scores increase.
- Mental health varies across different usage patterns.
- Relationship conflicts are more common among students with excessive social media usage.
