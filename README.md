## 📌 Project Overview

The **Student Social Media Addiction Dashboard** is an interactive Power BI project designed to analyze how social media usage affects students' academic performance, mental health, lifestyle, and relationships.

The dashboard transforms raw student data into meaningful insights using Power Query, DAX, KPIs, interactive visualizations, slicers, bookmarks, and drill-through pages.

---

# 🎯 Project Objectives

- Analyze students' daily social media usage.
- Identify social media addiction patterns.
- Measure academic impact caused by excessive usage.
- Evaluate lifestyle habits such as sleep duration.
- Analyze mental health indicators.
- Study relationship conflicts among students.
- Build an interactive business-style dashboard.

---

# 📊 Key Insights

- Students with higher daily usage hours generally have higher addiction scores.
- Reduced sleep duration is associated with increased social media usage.
- Academic performance declines as addiction levels increase.
- Mental health ratings vary significantly with lifestyle habits.
- Relationship conflicts are more common among students with higher social media usage.
